# 실제 사진 평가

지금까지의 검증 이미지는 모두 LFW에서 왔다. 이 평가는 LFW 밖의 실제 사진에서 학습된 62명을 얼마나 맞히는지 측정한다. 사진은 Wikimedia Commons에서 골랐고, 서비스와 같은 `/predict` 경로(얼굴 검출 포함)로 평가했다.

```
uv run python scripts/collect_real_photos.py   # manifest 생성 (이미 커밋되어 있으므로 보통은 필요 없다)
uv run python -m ml.evaluate_real              # manifest의 사진을 받아 SHA-256 확인 후 평가
```

이미지는 git에 넣지 않는다. `data/real_photos/manifest.json`에 사진마다 URL, SHA-256, 라이선스, 저자, 촬영 연도, 라벨 출처를 기록하고, 평가 스크립트가 그 목록대로 내려받는다.

## 정답 라벨

얼굴을 보고 누구인지 판단하지 않는다. 정답은 Commons 파일에 사람이 입력한 구조화 데이터 depicts(P180)에서 가져온다.

- 62명의 Wikidata ID는 `data/real_photos/people.json`에 있다. 이름 검색의 첫 결과가 LFW 시기 인물이 아닌 동명이인이었던 3명은 직함으로 다시 찾았다: George Robertson(Q333056, NATO 사무총장), Gerhard Schroeder(Q2530, 독일 총리), Igor Ivanov(Q378027, 러시아 외무장관).
- depicts로 5장을 채우지 못한 사람만 그 사람의 Commons 카테고리(Wikidata P373)에서 보충했다. 이때 depicts가 비어 있거나 그 사람 한 명인 파일만 쓴다. 이렇게 얻은 7장(Gray Davis, Paul Bremer, Ariel Sharon)은 `label_source: "category"`로 표시했다.

## 사진 선별

사람마다 후보를 고정 시드로 섞은 뒤, 아래 조건을 모두 통과한 사진을 최대 5장 골랐다. 2026-11-21에 수집했고 62명에서 287장이 나왔다.

| 조건 | 이 조건으로 빠진 후보 |
|---|---|
| depicts에 그 사람 한 명만 있다 | 1,931 |
| 큰 얼굴이 하나다. 두 번째 얼굴이 가장 큰 얼굴의 절반 이상이면 뺀다 | 440 |
| 제목이 여러 사람을 가리키지 않는다("X and Y", "X meets Y"). 한 사람만 잘라낸 `(cropped)` 파일은 허용 | 345 |
| 같은 사람의 같은 날 사진은 한 장만 | 96 |
| 원본 너비가 250px 이상이다(표준 썸네일 크기가 있어야 받을 수 있다) | 49 |
| 가장 큰 얼굴이 64px 이상이다 | 34 |
| 얼굴이 검출된다 | 31 |
| JPEG·PNG다 | 21 |
| 제목·분류에 그림, 동상, 밀랍 인형 같은 표현이 없다 | 20 |
| 직접 검토해서 쓸 수 없는 사진이 아니다(`data/real_photos/excluded.json`) | 16 |
| 서비스 업로드 한도(5MB, 2천만 픽셀) 안이다 | 1 |
| 얼굴 crop이 그 사람의 LFW 이미지나 이미 고른 사진과 상관계수 0.95 이하다 | 0 |

자동 규칙을 통과한 사진은 모두 한 장씩 훑어보았다. 그림, 트럼프 카드, 웹 화면 캡처, 도서관 카드, 분향소 영정, 단체 사진처럼 한 사람의 사진으로 쓸 수 없는 16장을 이유와 함께 `excluded.json`에 기록했고, 수집 스크립트가 이를 건너뛰고 다른 후보로 채웠다. 이 검토도 사진의 종류와 구도만 보았고 얼굴로 신원을 판단하지 않았다.

5장을 채우지 못한 사람은 9명이다: Guillermo Coria·Igor Ivanov·Jennifer Capriati 1장, Jeremy Greenstock 2장, Gray Davis·John Negroponte·Pete Sampras 3장, Roh Moo-hyun·Winona Ryder 4장. 대부분 depicts가 달린 파일 자체가 적었다.

## 결과

287장, 62명. 괄호는 95% Wilson 신뢰구간이다.

| 모델 | top-1 | top-1 (사람별 평균) | top-3 | 통과율 | 통과한 것 중 정답 | 참고: LFW test top-1 (검출) |
|---|---|---|---|---|---|---|
| cnn | 10.45% (7.4–14.5) | 9.84% | 22.65% | 7.67% | 12/22 | 30.65% |
| cnn-v2 | 23.34% (18.8–28.6) | 21.94% | 41.46% | 7.67% | 15/22 | 58.39% |
| pca-knn | 11.50% (8.3–15.7) | 10.73% | 18.47% | 3.83% | 5/11 | 14.52% |

촬영 시기별 결과다. LFW 사진은 2002~2004년 뉴스 사진이다.

| 모델 | 2005년까지 (99장) | 2006년 이후 (178장) | 연도 불명 (10장) |
|---|---|---|---|
| cnn | 11.11% | 10.11% | 10.00% |
| cnn-v2 | 28.28% | 19.10% | 50.00% |
| pca-knn | 16.16% | 8.99% | 10.00% |

라벨 출처별로는 depicts 280장, 카테고리 7장이다. 카테고리 7장은 표본이 너무 적어 따로 해석하지 않는다(cnn-v2 1/7).

## 해석

- 세 모델 모두 실제 사진에서 크게 떨어진다. 가장 좋은 cnn-v2도 LFW 검출 경로의 58.39%에서 23.34%가 됐다. 62명 무작위 추측(1.6%)보다는 훨씬 높지만, 서비스의 기본 모델이 실제 사진에서 4장 중 1장 정도만 맞힌다는 뜻이다.
- 순위는 LFW와 같다. cnn-v2가 cnn과 pca-knn의 두 배 정도이고, 두 모델의 신뢰구간과 겹치지 않는다.
- PCA+KNN의 하락폭(14.52% → 11.50%)이 작아 보이는 것은 원래 낮았기 때문이다. 통과한 것 중 정답도 5/11로 가장 낮다.
- cnn-v2는 2005년까지의 사진(28.28%)이 이후 사진(19.10%)보다 높다. 나이 차이 때문일 가능성이 있지만 차이의 z값이 1.76으로 5% 수준에서 유의하지 않다.
- unknown 임계값은 실제 사진에서도 보수적으로 동작한다. cnn-v2는 7.67%만 통과시켰고 그중 15/22(68%, 95% 구간 47–84%)가 정답이었다. LFW test의 91%보다 낮다.

## 한계

- 검출률 100%는 측정값이 아니다. 얼굴이 하나 검출되는 사진만 골랐기 때문이다. 실제 업로드에서는 얼굴을 못 찾거나 여러 얼굴 중 다른 사람을 고를 수 있다.
- 라벨은 depicts와 카테고리 정보를 그대로 믿는다. 제목 규칙과 직접 검토로 걸렀지만, 한 장에 여러 사람이 있는데 depicts에 한 명만 적힌 경우가 남아 있을 수 있다.
- Commons 사진은 행사·인터뷰·공식 초상이 많고, 최근 사진이 LFW 시기 사진의 두 배 가까이 된다. 사용자가 올릴 법한 사진의 분포와 같다고 보장할 수 없다.
- 287장이라 한 장이 0.35%p다. 모델 사이의 큰 차이는 믿을 만하지만 몇 %p 차이는 구간 안에 있다.
- 검색 결과는 시간이 지나면 바뀐다. 같은 스크립트를 다른 날 처음부터 다시 돌리면 다른 사진이 나올 수 있으므로, 커밋된 manifest가 평가 세트다.
