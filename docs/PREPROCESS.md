# 전처리 검증 결과 (Phase 2)

## sklearn 소스에서 확인한 동작

sklearn 1.9.1, Pillow 12.3.0 기준. `sklearn/datasets/_lfw.py`의 `_load_imgs`를 확인했다.

1. RGB 이미지를 `(78, 70, 172, 195)`로 자른다.
2. `resize((65, 87))`로 줄인다. 보간법을 지정하지 않으므로 Pillow 기본값인 BICUBIC이 쓰인다.
3. `float32`로 바꾸고 255로 나눈다.
4. RGB 채널을 가중치 없이 평균해 흑백으로 만든다.

크기는 `int(0.7 × 125) = 87`, `int(0.7 × 94) = 65`로 버림 처리된다.

`tests/test_preprocess.py`의 golden test는 62명의 LFW 원본 JPG 전체에 `ml/preprocess.py`를 적용한 결과가 `fetch_lfw_people` 배열과 픽셀당 오차 1e-5 이내로 같은지 검사한다.

## 전처리 불일치 실험

저장된 모델은 그대로 두고 test 이미지 310장의 전처리만 바꿔 정확도를 측정했다. `python -m ml.mismatch`로 재현한다.

| 서빙 전처리 | CNN | PCA+KNN |
|---|---|---|
| 공용 전처리 (기준) | 30.32% | 22.26% |
| PIL `convert("L")` 흑백 | 30.00% | 24.19% |
| bilinear 리사이즈 | 30.00% | 22.58% |
| nearest 리사이즈 | 29.35% | 21.29% |
| crop 10px 어긋남 | 4.52% | 4.19% |
| crop 없이 전체 리사이즈 | 2.26% | 1.29% |
| [0, 1] 스케일링 누락 | 6.13% | 14.84% |

## 해석

- 크게 무너지는 경우는 crop 위치, crop 누락, 스케일링 누락이다. CNN 정확도가 30.32%에서 2~6%대로 떨어진다. 62명 무작위 추측은 약 1.6%다.
- 흑백 변환과 보간법 차이의 영향은 작다. test가 310장이라 한 장이 0.32%p이고, PCA+KNN의 `convert("L")`처럼 기준보다 오른 경우도 있다. 이 차이로 어느 쪽이 낫다고 결론 내릴 수는 없다.
