# 얼굴 검출과 unknown 판정 결과 (Phase 4)

일반 사진은 YuNet으로 가장 큰 얼굴을 찾아 LFW와 비슷한 구도의 250×250으로 만든 뒤 기존 전처리에 넣는다. `ml/face_crop.py`가 구현이고, `?detect=false`면 이 단계를 건너뛴다.

## 구도 선택

Phase 2에서 crop이 10px 어긋나면 CNN 정확도가 30.32%에서 4.52%로 떨어졌다. 그래서 train 이미지 930장을 검출 경로로 통과시켜, 기존 전처리 결과와의 평균 픽셀 오차(MAE)가 가장 작은 방식을 골랐다. test는 쓰지 않았다. 이 비교는 일회성 스크립트로 수행했다.

| 방식 | 검출률 | MAE |
|---|---|---|
| Haar (scale 1.2, min neighbors 2), 확장 2.0배 | 927/930 | 0.0860 |
| YuNet 박스, 확장 1.95배, 위로 2% 이동 (채택) | 930/930 | 0.0723 |
| YuNet 5개 랜드마크로 평균 위치에 정렬 | 930/930 | 0.0928 |
| YuNet 눈 2개로 평균 위치에 정렬 | 930/930 | 0.0909 |
| 참고: 이미지를 10px 이동 | - | 0.1409 |

랜드마크 정렬이 박스보다 나빴다. funneled 이미지는 눈 위치 기준으로 정렬된 데이터가 아니어서(train에서 눈 위치의 x 표준편차가 약 8px), 랜드마크를 맞추면 오히려 학습 데이터의 구도에서 멀어진다.

## 검출 경로의 정확도

test 310장 기준이다. 합성 사진은 test 이미지를 1000×800 캔버스에 무작위 크기(180~700px)와 위치로 붙인 것이다.

| 입력 경로 | 검출률 | CNN | PCA+KNN |
|---|---|---|---|
| 검출 없음 (`detect=false`) | - | 30.32% | 22.26% |
| LFW 이미지 + 검출 | 100% | 30.65% | 14.52% |
| 합성 사진 + 검출 | 100% | 30.00% | 15.48% |

CNN은 검출 구도에서도 정확도가 유지됐고, 픽셀 위치에 직접 의존하는 PCA+KNN은 크게 떨어졌다.

## unknown 임계값

학습에 없는 LFW 인물(사진 20장 미만) 5,687명에서 1인당 1장을 쓰고, 인물 단위로 보정용 2,843명과 평가용 2,844명으로 나눴다. 임계값은 보정용 인물의 통과율이 5% 이하가 되는 가장 낮은 점수이고, `python -m ml.calibrate`가 manifest에 저장한다.

| | CNN | PCA+KNN |
|---|---|---|
| 임계값 | 0.8231 | 0.6000 |
| 학습에 없는 인물 통과율 (평가용) | 5.10% | 3.69% |
| 학습된 인물 통과율 (validation) | 2.14% | 4.95% |
| 통과한 것 중 정답 비율 (validation) | 66.67% | 63.04% |
| 학습된 인물 통과율 (test) | 9.68% | 5.48% |
| 통과한 것 중 정답 비율 (test) | 83.33% | 52.94% |

validation은 CNN이 학습에서 떼어 둔 15%(140장), PCA+KNN이 train의 5-fold 교차 예측이다.

## 한계

- 모르는 인물을 5%로 막으면, 학습된 인물도 대부분 `unknown`이 된다. test 기준 CNN은 약 10%, PCA+KNN은 약 5%만 통과한다. 정답 비율은 통과 건수가 적어 불확실하다(CNN test는 30건).
- 검증에 쓴 이미지는 모두 LFW에서 왔다. 합성 사진도 얼굴 자체는 LFW 이미지라서, 조명·각도·화질이 다른 실제 사진의 정확도는 측정하지 못했다.
