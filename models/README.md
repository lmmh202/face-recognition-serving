# Third-party models

## YuNet face detector

- File: `face_detection_yunet_2023mar.onnx`
- Source: [opencv/opencv_zoo, models/face_detection_yunet](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet), originally from [ShiqiYu/libfacedetection.train](https://github.com/ShiqiYu/libfacedetection.train)
- License: MIT, Copyright (c) 2020 Shiqi Yu. The full text is in [`LICENSE.yunet`](LICENSE.yunet).
- Paper: Wei Wu, Hanyang Peng, Shiqi Yu, "YuNet: A Tiny Millisecond-level Face Detector", 2023.

The file is redistributed unmodified. This project uses the fixed-input `2023mar` version because OpenCV 4.x runs it at the exact input image size.
